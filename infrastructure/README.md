# 🛠️ Module Infrastructure, Systèmes & Réseaux

Ce dossier regroupe mes travaux pratiques, scripts d'automatisation et projets d'architecture système réalisés pour acquérir des compétences solides en administration d'infrastructures IT.

---

## 📂 Organisation du Module

### 1. 🐧 Services Linux & Déploiement (`/linux-services`)
* **Projets :** Déploiement des solutions ITSM (**GLPI**) et de gestion des connaissances (**Wiki.js**).
* **Compétences :** Configuration de serveurs web (Apache/Nginx), bases de données (MySQL/PostgreSQL), scripting Bash et conteneurisation Docker.

### 2. 🪟 Active Directory & Automation (`/active-directory`)
* **Projets :** Administration sous Windows Server et automatisation PowerShell.
* **Compétences :** Création et gestion d'unités d'organisation (OU), utilisateurs/groupes, stratégies de groupe (GPO), et scripts d'intégration massive.

### 3. 🌐 Réseaux & Simulation Cisco (`/reseaux-cisco`)
* **Projets :** Conception et simulation de topologies réseau sur Cisco Packet Tracer.
* **Compétences :** Adressage IP (IPv4), découpage en sous-réseaux (VLSM), routage et configuration de commutateurs/routeurs.

### 4. 💻 Virtualisation & Lab (`/virtualisation`)
* **Projets :** Mise en place d'environnements de test sous VirtualBox et VMware.
* **Compétences :** Isolation réseau, snapshots, clonage et gestion de ressources d'analyses QA.
