
🎨 Styles CSS (Mise en forme & Structure)

📌 Ce que j'ai appris :

Séparation des responsabilités : Utiliser un fichier CSS externe permet de styliser proprement les éléments HTML (header, main, footer, body) sans alourdir le code des pages et en évitant la répétition des styles.

Mise en page et interactivité : J'ai exploré l'utilisation des styles de base (couleurs, arrondis avec border-radius, ombres avec box-shadow) ainsi que la gestion des menus déroulants dans la barre de navigation (nav, ul, li avec des effets :hover).

Modernisation avec Flexbox : Dans la deuxième partie, j'ai commencé à utiliser display: flex combiné avec justify-content et align-items pour aligner et espacer efficacement les éléments du header et de la page d'accueil.
